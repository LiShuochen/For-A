# 反差萌手办 STL 生成器 — 设计

日期：2026-10-07

## 1. 目标

生成可直接在拓竹（Bambu Lab）FDM 打印机上打印的 STL 手办。
- 身体：好看的女生身材 + JK 水手服 + 百褶裙 + 双马尾。
- 脸：用户本人（合照最右、戴眼镜的人，用户已声明是自己），自用 / 玩梗的桌面摆件。
- 成功标准：
  1. 三个版本（Q 版 / 写实 / 半身像）各导出一个封闭、单体、可打印的 STL。
  2. 把预览图和用户照片并排比较，一眼能认出是本人。
  3. 切片时没有"非流形 / 破洞"警告，薄壁和悬垂在可控范围内。

## 2. 假设（用户可纠正）

| 项 | 假设 |
|---|---|
| 打印机 | 拓竹 FDM，0.4mm 喷嘴，层高 0.08mm（Extra Fine）。建模体积按 256mm 立方内设计，也给 A1 mini（180mm）留余量 |
| 材料 | 单色 PLA；多色（AMS）作为里程碑 4，不影响主线 |
| 款式 | 水手服 + 百褶裙 + 双马尾 + 蝴蝶结 |
| 眼镜 | 做成贴在脸上的凸起细线（宽 0.8mm、高 0.5mm），不悬空，不易断 |
| 脸部素材 | 先用第 4 张合照里蹲着正对镜头的那张；用户若提供高清正脸自拍则替换 |

## 3. 交付物

```
out/jk_chibi.stl       Q 版大头，高 120mm，约 2.5 头身
out/jk_realistic.stl   写实比例，高 170mm，约 7 头身
out/jk_bust.stl        半身像 + 裙摆底座，高 110mm
out/previews/*.png     前 / 侧 / 后 / 脸部特写渲染图 + 和原照片的对比图
out/REPORT.md          每个模型的尺寸、体积、三角面数、预计耗材、悬垂面积、切片建议
```

高度比之前口头说的更大（100 / 150 / 90 → 120 / 170 / 110）：喷嘴 0.4mm，
脸越大越像，这是提升相似度成本最低的办法。高度是参数，可以改。

## 4. 架构

Python 包 `figurine/`，每个模块一个职责：

| 模块 | 职责 | 依赖 |
|---|---|---|
| `sdf.py` | 基本体（球、胶囊、圆台、椭球）、平滑并集、位移 | numpy |
| `body.py` | 躯干、手臂、腿、鞋、水手领、蝴蝶结；`style` 参数决定比例 | sdf |
| `skirt.py` | 百褶裙：半径 r(θ, z) = 基础圆台 + 正弦褶皱，下摆外扩 | sdf |
| `hair.py` | 刘海 + 后发 + 双马尾，贴肩，减少悬空 | sdf |
| `face.py` | 照片 → 关键点 → 深度浮雕高度图 | mediapipe, opencv |
| `head.py` | 头骨基体 + 脸部浮雕位移 + 眼镜凸线；输出接口固定，可换成外部头模 | sdf, face |
| `mesher.py` | SDF 体素化 → marching cubes → 平滑 → 抽稀 → 写 STL | scikit-image, trimesh |
| `check.py` | 水密性、单体、最小壁厚、悬垂面积、包围盒 | trimesh, scipy |
| `preview.py` | 软件渲染预览图、和照片并排 | matplotlib / pyrender |
| `build.py` | 命令行入口：`python -m figurine.build --style chibi` | 以上全部 |

**为什么用 SDF**：整个人是一个数学场，所有部件天然融成一个实心体，没有缝、没有穿插面，
marching cubes 出来的网格必然封闭，正好适合切片。体素边长默认 0.15–0.2mm，约为喷嘴线宽的一半。

## 5. 脸部流水线（相似度的关键）

1. 用 MediaPipe Face Mesh 在照片上取 468 个 3D 关键点，得到眼距、鼻宽、下颌轮廓、嘴宽等比例。
2. 以这些关键点把标准脸网格的比例对齐到用户的脸，得到"像本人比例"的深度基底。
3. 用照片亮度叠加细节：眉毛、眼睑线、嘴唇线、鼻翼，做成 0.2–0.5mm 的刻线或浮雕。
4. 把高度图映射到头部前半球，作为 SDF 位移。
5. 眼镜：按眼眶关键点生成两个圈、鼻梁连接和到耳朵的镜腿，做成 0.5mm 高的凸线。

**不会做到的事**：单张照片不是 3D 扫描，不会 1:1 还原。预期效果是"认得出是你"，
不是"雕塑级肖像"。想更像，头部是可替换模块：用 Meshy / Tripo / Hunyuan3D / Polycam
生成头部，再由 `head.py` 对齐到身体上。

**风险与退路**：
- MediaPipe 在 Python 3.13 上可能没有现成轮子 → 用 `uv` 建 3.12 虚拟环境。
- 模型文件下载被网络策略拦 → 退到 OpenCV 内置检测加纯比例椭球 + 亮度浮雕。
- 合照里的脸只有约 100 像素宽 → 先放大，再做关键点；效果仍受限，建议用户补一张自拍。

## 6. 可打印性（0.4mm 喷嘴，0.08mm 层高）

- 底座：直径约身体最大宽度 1.3 倍、厚 3mm 的圆盘，防倾倒。
- 最小结构：承重部件 ≥ 1.2mm；脸部浮雕凸线 ≥ 0.4mm 宽、0.3–0.5mm 高。
- 悬垂：下巴、头发、手臂会有 >45° 悬垂，建议用拓竹的树状支撑；`check.py` 会报告悬垂面积。
- 方向：立着打印，脸朝前，竖直面上 0.08mm 分层最细腻。
- 预计时间：Q 版约 10–14 小时，写实约 14–20 小时，半身像约 6–9 小时。实际以切片软件为准。

## 7. 验证

1. `check.py` 对三个 STL 全部通过：水密、单一连通体、无自交、尺寸等于目标值 ±1mm。
2. 最小壁厚 < 0.8mm 的区域占比报告出来，核心结构不得出现。
3. 渲染前 / 侧 / 后 / 脸部特写，逐张目视检查；脸部对比图并排放在用户原照片旁。
4. 输出文件用 trimesh 重新读取，确认可被第三方工具加载。

## 8. 里程碑

0. **环境和可行性探针**：装依赖，确认关键点能在合照上跑通，决定脸部方案走主线还是退路。
1. **Q 版全流程**：身体 + 裙子 + 头发 + 脸，端到端出 `jk_chibi.stl` 和预览，给用户看。
2. **写实版和半身像**：只调比例参数，复用同一套代码。
3. **根据用户反馈迭代**：像不像、裙子、发型、比例。
4. **（可选）多色**：按区域（皮肤 / 头发 / 衣服 / 裙子 / 鞋）导出对齐的分件 STL，供拓竹 AMS 配色。

## 9. 不做

- 不做动画、骨骼、可动关节。
- 不做真人级皮肤纹理。
- 不为多个人做通用化，只服务这一个人的脸。

## 10. 隐私

照片只在本机处理，复制到 `assets/`（已加入 `.gitignore`，不会提交），不上传到任何外部服务。
若用户选择用 Meshy / Tripo 等外部服务生成头模，由用户自己上传，我不代传。
